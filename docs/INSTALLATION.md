# Installation

## 1. Create the special profile repository

GitHub only renders a profile README from a repo named **exactly** after your username:

```
DaniyalAsif7778/DaniyalAsif7778
```

If it doesn't exist yet, create it on GitHub as a **public** repo with that exact name.

## 2. Push this folder's contents to it

```bash
git clone https://github.com/DaniyalAsif7778/DaniyalAsif7778.git
cd DaniyalAsif7778
# copy everything from this github-profile/ folder in here, then:
git add .
git commit -m "Add premium SVG design system profile"
git push
```

The repo root should end up looking like:

```
DaniyalAsif7778/
├── assets/
├── .github/workflows/update-stats.yml
├── scripts/generate-stats-card.js
├── README.md
├── LICENSE
└── docs/
```

## 3. Enable the live stats card

The stats card at `assets/stats/stats-card.svg` is regenerated by a GitHub Action, not by anything running in the README itself (GitHub strips scripts from rendered markdown, so this has to happen server-side in CI).

Nothing to configure — `.github/workflows/update-stats.yml` uses `secrets.GITHUB_TOKEN`, which every repository already has automatically. Once the workflow file is pushed:

- It runs once a day at 06:00 UTC and commits the refreshed SVG if the numbers changed.
- You can also trigger it immediately: **Actions tab → "Update GitHub Stats Card" → Run workflow**.
- First run after setup: give it a minute, then refresh your profile page.

If you ever rename your GitHub account, update the `GITHUB_USERNAME` value in `.github/workflows/update-stats.yml` (and the default in `scripts/generate-stats-card.js`) to match.

## 4. Verify

Visit `https://github.com/DaniyalAsif7778` — the hero banner, badges, stats card, and project cards should all render. If an image shows as a broken icon instead, see the troubleshooting note in `docs/README-INTEGRATION.md`.

## Requirements

- No build step for the README itself — every asset is a plain `.svg` file.
- The stats workflow needs Node 20+, which `actions/setup-node@v4` installs automatically in CI. You don't need Node installed locally unless you want to run `scripts/generate-stats-card.js` by hand to preview a change.
